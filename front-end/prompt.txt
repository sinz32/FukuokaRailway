실시간 전철 위치를 보여주는 웹사이트을 만들어주세요

사용 언어 및 환경 : HTML, CSS, JavaScript. 웹 프론트엔드 바닐라
결과물 형식 : 단일 .html 파일

안드로이드 앱에서 보이는 AppBar와 유사한 것이 웹 상단에 보입니다.
AppBar의 오른쪽에는 햄버거 버튼이 있습니다.
 - 버튼을 누르면 서랍메뉴가 열립니다.
 - 메뉴에는 다음과 같은 노선들과 닫기 버튼이 있습니다.
 - 노선 목록 : 지하철 공항선, 지하철 하코자기선, 지하철 나나쿠마선, 니시테츠 텐진오무타선, 니시테츠 다자이후선
 - 노선 목록에서 노선을 선택하면 해당 노선의 실시간 열차 위치 정보를 ajax로 불러와서 보여주며, 서랍메뉴가 닫힙니다
 - 닫기 버튼을 누르면 서랍메뉴가 닫힙니다.
웹 메인화면 App Bar아래에는 `지하철 공항선`, `지하철 하코자기선`, `지하철 나나쿠마선`, `니시테츠 텐진오무타선`, `니시테츠 다자이후선`, `웹사이트 정보` 버튼이 배치됩니다.
 - 해당 버튼을 누르면, 서랍 메뉴에서 선택한 것과 동일하게 동일하게 해당 노선의 실시간 열차 위치 정보를 ajax로 불러와서 보여주며, 웹사이트 정보 버튼은 아직 아무런 기능이 없습니다.
 - 기존에 메인화면 AppBar 아래에 있던 것들이 사라지며, 화실시간 열차 위치 정보가 표시됩니다.

ajax 요청 주소 : `https://api.example.com/test?line=${line}`
 - ${line}에는 각각 A, H, N, T, D가 들어갑니다.
 - 제가 실제 엔드포인트 주소로 변경할 수 있도록, 자바스크립트 소스코드 부분 상단에 상수로 선언해주세요.
